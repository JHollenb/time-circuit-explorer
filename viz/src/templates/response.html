What historical computation does this reuse?

Each curve is bound to a supplied context and known seed. This is conditional RGB interpolation, not a general latent decoder or a new-prompt generator. The dense generator above still evaluates the complete denoiser equations and uses a native encoder and VAE.

Follow the factorization and evidence

Below α = .25, Ŷ = Y₀ + 4α(Y₀.₂₅ − Y₀). Above it, Ŷ = Y₀.₂₅ + ((α − .25)/.75)(Y₁ − Y₀.₂₅). Each pixel uses explicit float32 boundaries, then clipping and nearest-even rounding. This recovers all 16 recorded NumPy primary outputs pixel for pixel.

The historical path was defined by late-latent state interpolation and a native VAE consumer. This browser program consumes context and dose directly; it does not advance a latent or run the native model. The original held files were scored only after the predictions sealed.

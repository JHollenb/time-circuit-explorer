# Distinguish feature geometry from context-state capacity

Status: proposed after [cycle6](../compiled-context-statistics.md) and Astra's two code/newest-post reviews. No diagonal-conditioned serving or image result is claimed. The unchanged feature family collapsed at selected keys; retrospective means/scalar balancing improve it but leave large error. Those heuristics are not optimized oracle upper bounds.

## The next smallest discriminator

Use only the immutable full-assay ports, original sealed feature draws and exact saved reference heads. Preserve the same14 prompts, ranks16/32/64 and40 mask-selected queries. No new native inference, original checkpoint reads or online-serving claim. Run one finite guarded CPU mrun lease on the host holding these arrays, without retries.

For fixed centers a,b and any invertible positive diagonal D,

\[
x'=D(x-a),\quad y'=D^{-1}(y-b),\quad \beta(y)=a^\top y,
\]
\[
x'^\top y'+\beta(y)=x^\top y-x^\top b+a^\top b.
\]

Thus exact normalized attention is unchanged. For retrospectively measured coordinate moments

\[
A_\ell=E[(x_\ell-a_\ell)^2],\qquad
B_\ell=E[(y_\ell-b_\ell)^2],
\]

the diagonal choice

\[
D_{\ell\ell}=(B_\ell/A_\ell)^{1/4}
\]

minimizes the summed norm contribution \(\sum_\ell(D_{\ell\ell}^2 A_\ell+D_{\ell\ell}^{-2}B_\ell)\). It does not minimize normalized-head error. Residual anisotropy needs measurement; the existing large mean component alone does not establish it.

Freeze these diagnostics before execution:

- Centers remain the current all512-query mean and active-key mean, fitted to complete held arrays. This is retrospective lookahead. Preserve the padding dominance of short-prompt query means as a limitation.
- Compare unchanged, centered/scalar-balanced and centered/diagonal-balanced using the same Gaussian rows. Include a diagonal-only variant to separate centering from reciprocal geometry.
- Use coordinate moment floors at1e-12 times the corresponding mean moment; record all affected coordinates and raw/floored moments. If an entire side's moment is zero, use unit scale and label that degenerate geometry. A1e-10 sensitivity arm records regularizer dependence. Floors choose a finite diagnostic transform, not an accuracy gate or a changed reference.
- Retain distributions of transformed pair-sum norms/log unnormalized-kernel variance, exact gauge-probability closure, key TV/entropy/mass/address, and raw/BF16 head error. Split active and padding queries, and preserve rank trajectories and counterexamples.
- Validate new diagnostic arithmetic on tiny synthetic operands, then authenticate the real saved-array job. Finite/shape/hash/identity contracts protect the instrument; accuracy is observed without suppressing poor arms.

A fixed diagonal transform adds only coordinate constants and elementwise arithmetic to the *hypothetical* serving rule; it does not change r×d context-state size. This assay does not establish a source-frozen transform, a new own-state rollout, later-encoder fidelity, pixels or the strict zero-neural objective.

## What the observation will decide

If diagonal geometry substantially improves multiple reads, the next experiment can freeze a source-only token/position distribution and its coordinate recipe before fresh raw strings. The source distribution must be explicit in positioned space; an unrotated lexical mean cannot silently stand in for a positioned mean. Charge compilation, tables, constants, feature formation and retained learned information.

If the feature family remains inaccurate, compare its representation with an oracle low-rank diagnostic on a **common unmasked query/key bank**, applying causal masks afterward. Do not fit separate rank64 decompositions to short prompts with fewer than64 active keys; that would make reconstruction trivial without a reusable feature map. Freeze common-bank selection independently of observed error, retain normalization and masking effects, and label all target-assisted fitting as capacity analysis. This future diagnostic is not yet staged or specified as a serving algorithm.

Do not jump to high-degree polynomial features or an exact sparse correction selected by evaluating every exact score. A full degree-two monomial expansion in128 dimensions already has8,385 coordinates including constant and linear terms. A sparse selector that first evaluates all query/key scores has retained the expensive computation. Any later alternative must improve the requested prompt-to-image path rather than merely rename learned operations.

The full goal remains contextual conditioning from raw prompts, autonomous state advancement, general non-neural pixel production and independent prompt-faithfulness/quality evidence.

Write E=H0 and A for the complete mixed head bank. Ignoring notation for the declared finite conversions, this boundary computes

$$R=E+W_O A,\quad X=N_{\mathrm{post},0}(R),\quad H_1=R+W_D[\operatorname{SiLU}(W_GX)\odot W_UX].$$

The inspected source consumes this actual H1 at original native layer1. That layer's input normalization and original Q/K/V projections, query/key normalization and position factors form contextual reader operands. Source positions/masks and the backend's BF16/reduction/layout policy remain part of the interface. Later operand values depend on H1, not only on the current token and absolute clock. A token-local cache therefore cannot be declared sufficient for this boundary without further evidence.

The next action is to specify and implement **one source-derived register/update/readout family** at this interface. Its contract must name:

1. An initializer from raw ordered input, with tokenizer/lexical compilation and any other learned work accounted for. A supplied native R or H1, a hand-inserted scene parser, or a whole-history answer cache does not close this dependency.
2. Its retained state z, actual reads/writes and update program on its own produced states. Treat addresses, coefficients, values, contextual residuals and semantic claims separately. The current weight port is an available bounded component, not a substitute for the other inputs.
3. A readout that produces the operands required by a named layer1 consumer, with finite shape/layout/value contracts. If some output rows or heads are omitted, state which actual consumer can legally omit them; do not infer this from token padding alone.
4. Every online primitive and offline asset: source acquisition, compilation, routing, state maintenance, scalar/vector products, nonlinearities, normalization, readout, transfer and decoding. Re-evaluating original learned affine/gated maps in a different language, or training a neural student, does not meet the goal. Model-derived lookup/program assets remain charged.
5. One smallest controlled input contrast that actually reaches the proposed state/readout, preserving zero effects and wrong/unknown-input controls. Freeze the contrast before outcome inspection. A new reference may diagnose a proposed program; it cannot become a serving operand.

For an encoded representation, the mathematical question is closure on reachable own states,

$$E_{p+1}(F_p(s,u))\approx G_p(E_p(s),u).$$

The symbol E_p here is an encoding map, distinct from lexical E=H0 above. Identity encoding plus the original neural computation satisfies a trivial commuting relation but does not meet the computational goal. A compact-looking state supplied by an oracle also fails the initialization requirement. Neither observation rules out a useful source-derived program.

Keep local operator error separate from propagated state error. With original tail T and candidate tail T_hat, an actual future discrepancy factors as

$$\widehat H_1-H_1=[\widehat T(\widehat R)-T(\widehat R)]+[T(\widehat R)-T(R)].$$

The first term tests the candidate operation on its own input; the second tests consequences of its upstream state. A matched-parent diagnostic can distinguish them but is not an autonomous improvement by itself. A successful local decoder or state fit does not establish the future transition. Existing [history-reader evidence](../../../saturn/experiments/2026-11-07-history-reader-role-cut/FINDINGS.md) already localizes payload→native block→next query in another specimen, so repeating that localization would not supply the missing initializer/update here.

No concrete non-neural H1 constructor has been established. Do not automatically run all-head value mixing, a native block/image suffix, a projection/rank sweep, or another table expansion. First construct a candidate with this dependency ledger; use the smallest source/consumer experiment that can then distinguish it from the existing original computation.

# Jointly construct the contextual baseline and response

Selected after the [109 normalization audit](../coupled-normalization.md) and [Astra actual-result review](../results/coupled-normalization-evidence/advisor-actual.json). This is a representation/objective decision, not an executable optimizer contract. Status: unimplemented, untested and unrun. No new fit, native evaluation, prompt or image follows automatically.

## The distinction the program must preserve

The existing two-slot writer freezes its first endpoint-trained slot and fits an added contrast-aware slot. It can match a small raw difference while carrying nearly common endpoint errors. At the next normalization, the own response error is71.42%of native response norm. Its D and B discrepancies reinforce. The D vectors are nearly parallel but have the wrong gain; the finite gamma-weighted baseline endpoints still have83.89%/91.37%native-relative errors. A target-assisted gain correction neither reconstructs those endpoints nor supplies the baseline feedback.

The [106 capacity result](../finite-writer-capacity.md) also excludes another routing-only repair using the frozen nine measured atoms for most vessel-padding response. It is evidence against that frozen vocabulary, without a bound on a newly constructed vocabulary. Row9 is one local discriminant, not the complete contextual objective.

## Change the construction while retaining the serving grammar

Allow both slots' routing and constant write vectors to be constructed jointly. Remove the frozen first-slot/added second-slot organization and the frozen atom identities. Retain the existing branch/copy/add/BF16 serving grammar, two slots, depth at most4, at most16leaves per slot and complete2560coordinate write vectors. These are current budget ceilings, not a claim that a future fit attains32 useful leaves or solves the capacity gap. Do not increase them automatically when a candidate is poor.

Serving must construct its finite H state from its own compiled lexical values and causal token/history features. It must not read paired-case IDs, teacher H1/Z, native radii, target-derived gain, future tokens or a whole-prompt output cache. Original normalization/gamma may evaluate offline candidate futures as paid research feedback; it must not be inserted as a serving shortcut. Fresh serving continues to exclude neural frameworks and learned affine calls.

Fit baseline geometry and contextual response together. The proposed objective balances finite H endpoints and paired H differences with source-policy Z endpoints and paired Z differences. Balance histories/pairs and active/padding strata separately; keep absolute observations for zero references. The exact denominators, weights and finite evaluation order belong to the later execution contract. Native target assistance is permitted for offline construction only and remains visible in its compute account.

## Make the next run constructive and bounded

Before implementation, specify one finite candidate-construction algorithm, exact source identities, the allowed dictionary/routing mutations, total candidate count and paid normalization work. Use Saturn to retain a common parent program, inspect each candidate's own finite state through its consumer and restore the parent when a candidate is rejected. Do not replace this with an unconstrained epoch loop. Rejected candidates remain evidence.

The smallest useful run should emit one complete input-owned program and measure its whole discovery panel, including vessel padding and the cube pair, followed by a sealed known transfer panel. Historical transfer targets have already been observed, so label them transfer rather than newly held-out evidence. Preserve endpoints, responses, signed error interactions, regressions and cost. A newly held-out arbitrary-prompt claim requires a separate later input policy and native/image evaluation.

Use one guarded mrun lease, with actual device, intent-first resources, strict preflight, explicit physical work, no retries or automatic expansion. Source review and the smallest supplied mechanics precede first execution. Integrity/resource conditions can stop corrupted or unsafe work; endpoint error, response quality and per-row wins remain observations. No proxy gate certifies arbitrary-prompt generation.

## What would count as progress

The constructive question is whether the same small non-neural program can generate a more consumer-useful baseline and its contextual response from its own input. Merely improving one row, rescaling D with targets or reducing raw response error while damaging the state would not settle that question. Keep all such trends visible, with their scope.

This next construction still cannot by itself close the full encoder, autonomous diffusion or general pixel decoding. Arbitrary raw prompt to faithful image with zero neural serving evaluations remains the active goal. Full research/storage108 is current; next periodic review111, or earlier material route-changing evidence/pressure.

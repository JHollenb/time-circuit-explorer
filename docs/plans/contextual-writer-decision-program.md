## Actual initializer and serving language

Run the bound tokenizer on the raw string and form the complete ordered token/mask/position packet. Initialize lexical H0 through the existing full-vocabulary compiled atom table. Keep all of that input as owned registers; source-known fixed contextual constants may supply positions0–1. Do not make the discovery vocabulary, a prompt template family or a hidden-state sample the admitted raw-input domain.

For every other row, use one shared rule grammar:

$$\lambda_{k,p}=\operatorname{route}_{T_k}(\phi(z_p,p)),\qquad r_p=\sum_{k=1}^{K}s_{k,\lambda_{k,p}}e_{a_{k,\lambda_{k,p}}},$$

$$\widehat H_{1,p}=\operatorname{finite\_add}(H_{0,p},D r_p).$$

Here z is the program's owned causal token history and state, phi contains explicitly declared input-derived features, T are branching programs, s are signs or zero, a are addresses into one bounded shared writer dictionary D, and e_a is a dictionary address. The displayed matrix expression is notation: serving must implement selected copies/additions, **not a learned dense readout**. Freeze the finite addition/rounding policy before a run. Predict every active and padding row; leave no oracle-filled part of H1.

Permitted predicates include token identity/set membership, integer position/mask/count tests, ordered register reads and declared coordinate/word comparisons of owned compiled lexical atoms. Feature extraction, causal history maintenance and state ownership are paid computations. Do not form original gate/QK projections to select a cell. Inputs may not include native R/H1, prompt IDs/hashes, a supplied support route, target-derived features or complete-history lookup keys.

Leaves select local writer atoms shared across histories and positions. They may not contain complete 512-row outputs, a native suffix, arbitrary affine leaves or source-model fallback code. A bounded dictionary can still memorize examples in disguise; local output shape alone does not exclude that. Audit predicates, dictionary sharing, absolute-clock dependence and transfer to separated histories. The construction is an approximate learned non-neural program; it is not an exact algebraic compiler or evidence of a sufficient state representation.

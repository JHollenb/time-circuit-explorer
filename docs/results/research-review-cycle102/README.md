## Alternative and limits

A full-vocabulary unary cofactor is the strongest exact alternative at the first variable token after a fixed prefix. One 151,936-token × 2,560-word BF16 state table alone is 777,912,320 bytes; all 28 states would be 21,781,544,960 bytes before provenance, tokenizer, compilation and other costs. These are literal uncompressed sizes, not lower bounds. This supplies one unary address and does not provide a reusable contextual successor for later rows. It is not selected for automatic expansion.

The chosen family has no measured quality or economy yet. Full own-state encoder/denoiser continuation and non-neural pixels remain open. Failure of one small grammar would constrain that grammar, not symbolic computation generally; absence of a global proof is not a discovery stop gate.
